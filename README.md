# ShotGrid-Houdini-Contexted-Scene-files

A context-driven USD workflow for Houdini.

This tool lets artists select a working context and automatically manages USD saving and path generation behind the scenes.

Instead of manually creating directories, naming files, or worrying about where your USDs should live, the pipeline handles it for you — consistently and predictably.

---

## Features

- Context-driven workflow
- Automatic USD path generation
- USD layer stack management


---

## How It Works

1. Select your working context
   - Sequence
   - Shot

2. Load your USD Layerstack and start working in Houdini

3. Save your work with the USD out hda

4. Save your caches with the NFA Filecache

5. All USD exports, caches, layers, and publishes are saved to the correct location
